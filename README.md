This is a popular basic excersize to understand how Monte Carlo simulations work (https://en.wikipedia.org/wiki/Monte_Carlo_method).

The script puts random points on the coordinate space containing a circle inscribed into a square and approximates π from their ratio.
(**π is 4x the ratio of points in circle to all points**, which means that an inscribed circle's area is π/4 times square's area).

It uses MatPlotLib and NumPy libraries.
